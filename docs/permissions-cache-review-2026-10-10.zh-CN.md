# EchoCode r8：权限语义、工作区缓存与模型表格

日期：2026-10-10。版本：0.3.20 r8 Windows x64 预览版。

## 权限名称与实际行为

参考 [Codex 官方沙盒与审批说明](https://learn.chatgpt.com/docs/sandboxing) 及 [权限配置](https://learn.chatgpt.com/docs/config-file/config-basic)：审批策略控制何时询问，沙盒控制文件与网络边界；`on-request` 不是对每次写入都询问，`never` 也不自动等于解除沙盒。

旧版输入框菜单只有“完全访问”复选项，实际仅切换 `approvalPolicy`，文件范围和沙盒不变。本轮替换为 Kobalte 单选菜单，并以真实配置判定当前档位，避免把“工作区写入 + 永不询问”错误显示为完全访问。

| 菜单 | 文件 / 沙盒 | 审批及附加行为 |
| --- | --- | --- |
| 请求批准 | `workspace-write` / `workspace-write` | 工作区及明确配置的额外目录内，结构化写入、补丁、复制、删除直接执行；工作区外文件请求限定目标的授权。命令执行开关启用，但当前 Windows 命令仍要批准，见下方边界 |
| 完全访问 | `unrestricted` / `danger-full-access` | `never`，启用网络和命令，不逐次询问；不自动增加电脑操控允许应用，不修改项目根和凭据。保留现有宿主工具校验及破坏性 Shell 操作限制 |
| 只读 | `read-only` / `read-only` | 不提供修改文件、本地命令、浏览器交互及电脑操控工具。读取网页可继续使用只读工具；修改前需要切换权限 |
| 详细权限设置 / 自定义 | 用户配置组合 | 支持独立配置审批、沙盒、文件范围、网络等；非标准组合明确显示“自定义权限” |

**尚未达到的 Codex 等价能力：** 当前 Windows 后端为 Job Object + 受限令牌，提供进程树、资源和权限限制，但没有完整的操作系统文件/网络隔离。因此“请求批准”对本地命令仍采用额外批准，菜单会直接说明；不能把它宣称为 Codex 的完整沙盒，也没有实现自动审批审查器。本轮没有静默启动完整权限、安装全局沙盒组件或修改系统 ACL。

旧配置迁移到 schema 14：旧 `on-request`、`on-failure`、`untrusted` 的保守实际行为映射成“每次询问”（`always`），避免升级时自动减少询问。新建配置和用户明确选中的“请求批准”使用新的边界语义。UI 在任意对话任务运行、保存或切换期间禁用权限切换；保存失败保持此前有效状态。

## 外部文件授权与恢复

- 只对宿主自己的具体文件工具启用边界判断，插件不能通过工具名伪装成内置写入工具。
- 授权弹窗展示具体目标和操作；拒绝、无界面或取消时不执行。保留只读、用户本轮限定目标和受保护系统路径检查。
- 单次/会话授权绑定操作参数与规范化后的实际目标。每次授权只应用到复制的工具实例，不修改运行配置、全局额外可写目录或其他会话权限。
- 审批等待期间重新校验实际路径，防止目录别名变化后写入另一个目标。
- 已批准文件的宿主授权标记随文件快照持久化，用于重启后回退和分支重放；只允许恢复原来已批准的具体文件。该标记不能通过工具/插件 JSON 伪造，不授予下一次模型调用访问权。
- “本会话都允许”改为“本会话允许此操作”，符合宿主按具体操作指纹记忆的真实范围。

## 工作区缓存与表格

- 工作区头部新增“缓存 XX%”入口；弹层显示当前会话累计命中/未命中输入 tokens、最近一次请求比例和使用统计入口。
- 百分比直接按对应范围的计数计算，不把最近一次请求的比例冒充会话累计比例；无缓存计数时显示破折号。
- 会话切换关闭旧弹层，沿用现有按项目/会话过滤的实时 usage 更新，不串到其他任务。
- 模型配置行改为顶部对齐，“来源”说明在输入框下方占独立空间；上下文、模型 ID、显示名称及操作按钮不会因为说明文本而上下错位。增加上下文输入框可访问名称，验证深浅主题、多个模型和窄窗口。
