# EchoCode r9 界面验收

版本：0.3.20 r9 Windows x64 预览版。日期：2026-10-10。

按用户四张截图完成：缓存入口仅显示图标与百分比；模型行不再显示“手动设置”等来源副标题；侧栏品牌标志下增加分隔线；关于页与侧栏使用同一图标；设置页和工作区共享侧栏收起状态。

侧栏收起与展开由同一个状态驱动，顶栏按钮和 Ctrl+B 都有效。桌面宽度下收起设置分类栏后正文随之扩展；窄窗口下分类选择器也随状态隐藏/显示。切换工作区和设置不重置该状态，隐藏的分类项不进入键盘焦点，未保存草稿继续保留。

验证结果：

- TypeScript 检查、108 项前端单测及 Vite 生产构建通过。
- 72 项浏览器 UI 用例通过，包含缓存详情、模型数值修改、深浅主题、窄屏、侧栏宽度、跨页面折叠、Ctrl+B 和草稿保留。
- 13 个真实 Wails 宿主场景通过，包含实际菜单、缓存、压缩/重启、文件回退及新增侧栏同步和图标一致性。
- Wails Windows 生产 clean build 通过；生产程序检查无验收调试端口/隔离目录开关。

本轮没有 Go 业务源码修改，后端及权限边界沿用 r8。当前 Windows 后端仍无完整的操作系统文件/网络隔离，“请求批准”模式下命令仍额外审批；r9 没有改变此能力边界。

测试使用隔离配置和合成工作区，没有调用付费模型或更改用户保存的供应商设置。未创建提交或发布 Release。
