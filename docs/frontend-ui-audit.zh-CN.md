## 2026-10-10 r6：文件与工作面板遗漏修正

用户截图指出目录树选中项仍有旧版亮色竖线。此前界面套件对文件面板主要验证入口、空态和尺寸，没有用包含目录与文件的数据核对选中效果；这部分覆盖不足。

- 目录树、文件更改列表和 Git 文件列表统一采用 `SelectableRow`；去除旧的内嵌选中竖线，使用整行底色，区分悬停、选中、键盘焦点和不可用项。
- 文件/更改、项目/Git 更改、Git/终端、右侧工作面板、浏览器/检查器及工作表切换接入现有 Kobalte Tabs。`PanelTab` 保持按需挂载内容的 ARIA 关联；浏览器切换到文件页时保留实例与标签状态。
- Git 分支选择使用现有 Kobalte Select，差异来源使用 RadioGroup；文件面板图标操作使用共享 TooltipButton。
- CodeMirror 保留语法高亮，调整主题扩展优先级，修正旧 One Dark 背景覆盖工作台色板的问题；当前行也移除亮色竖线。
- 文件树补齐方向键展开/收起、父子节点导航、Home/End 和单一 Tab 焦点；稳定已展开行的 DOM 身份，避免展开目录后丢失焦点。
- 新增 `panel-fixture.ts` 和 `panels.e2e.ts`，覆盖实际目录数据、深浅主题、选中样式、代码背景、键盘操作、差异、分支选择、工作表、窄屏，以及浏览器实例保留。
- 原来依赖具体 `onClick` 源码字符串的浏览器保留测试，改由真实浏览器的挂载标记和标签状态验证。

此轮修改前端工作面板，保留 r5 的 Agent、协议与安全修复。TypeScript、105 项前端单测、60 项浏览器回归和 Windows Wails clean build 全部通过；真实 Wails 宿主 10 个场景通过，包含实际点击文件树并核对代码预览。单测数量减少 1 是因为用行为回归替换了源码字符串断言。截图和日志放在 `%TEMP%/echocode-panel-review-20261010`。

| 从宽窗口缩窄后，项目侧栏盖住终端操作 | 侧栏初始折叠状态没有响应窗口变化 | 窄窗口自动收起侧栏，用户仍可主动展开 |
| Git/终端初始高度过小 | 缺失存储值被 Number(null) 转为 0 | 没有偏好时使用 280px 默认高度，保留用户已保存值 |

## 验证方式

- `layout-audit.e2e.ts` 遍历全部设置分类，在深浅主题及 1920/1280/960px 宽度下检查溢出、双栏间距、保存区是否遮挡正文；追加 720px 和 125% 界面缩放检查。
- 使用包含多个 MCP 服务、多个插件、不同缓存比例和累计用量的测试数据，避免只检查空白状态。
- `settings-flows.e2e.ts` 验证 MCP 配置保存与重连、插件权限与确认、统计数据范围、账单操作及失败提示。
- 工作台面板在 1440/960/720px 检查；图片预览验证 Tab 焦点限制与 Escape 关闭。
- 保留既有扩展、聊天、菜单、附件、输入历史、停止、审批、主题及缩放回归。

测试使用独立的 Vite 服务（默认 34117 端口），与用户预览的 34116 分离，避免复用旧样式缓存。截图与布局测量记录输出到被 Git 忽略的 `frontend/test-results/`。

验证命令：

```powershell
cd frontend
bun run check
bun run test:ui
```

旧的圆形用量卡片源码字符串断言已移除，对应行为改由浏览器中的数据范围与计量条验证覆盖。

## 验证边界

浏览器测试使用内存 Wails 模拟接口，不执行真实 Shell、MCP/插件进程或官方账单查询。Windows 桌面构建已成功；原生浏览器表面、电脑操控、真实供应商及办公软件打开保真度仍需桌面人工验收。后端全量测试包含临时文件和本地协议/进程测试，具体边界见 [项目检查与修复记录](project-review-2026-10-10.zh-CN.md)。
