## 新的工作台

- 统一低对比深色与浅色界面，重做设置、使用统计、扩展、MCP、插件、文件树及 Git/终端面板。
- 菜单、下拉、滑块、选项卡、弹窗与折叠区采用共享控件，补齐键盘操作、焦点恢复、动画和减少动态效果支持。
- 精简导航和重复标题，应用顶栏跟随页面名称；工作区与设置页共用侧栏收起状态和拖动宽度。
- 对话及输入框随面板宽度伸缩，修正回复耗时与按钮间距、模型上下文输入行对齐，以及模型菜单在窗口边缘的选择问题。
- 模型公开返回的思考内容在生成、完成、切换会话和重启后保持可查看，避免被历史刷新覆盖。

## 上下文与缓存

- 工作区直接显示上下文用量和缓存命中率，区分会话累计缓存与最近一次请求。
- 新增手动压缩入口，补强自动整理和长工具循环的预算检查，保留当前任务要求及最近完整的工具调用/结果。
- 压缩视图可持久化和恢复，保存失败回滚，不删除原始聊天记录或文件检查点。

## Agent 与协议修复

- 完善 OpenAI Chat Completions、Responses 与 Anthropic Messages 的工具参数、调用 ID、并行调用、思考字段和不透明续接信息回传。
- 修复部分中转的流式结束、异常 EOF、空回答、工具失败结果、图片回传及 Responses 思考混入正文问题。
- 修复 Windows URL 被误判为驱动器路径、目录链接越界和电脑操控聚焦失败。
- 补强事件 HEAD、配置及项目清单的保存失败处理，避免界面报成功后丢失结果；后台任务、回退、分支切换与自动化状态更加一致。
- 修复插件/扩展安装卸载失败回滚、子代理结果竞争，并支持插件二进制产物与已授权外部文件的快照恢复。

## 权限与升级

- 权限菜单提供“请求批准、完全访问、只读”及自定义设置，按文件范围、沙盒和审批策略的实际组合显示状态。
- “请求批准”对工作区内结构化文件修改直接执行；外部文件操作需要具体目标授权。授权不会扩展到同目录其他文件或其他会话。
- **升级保留原有审批强度。** 旧版保守审批配置迁移为“每次询问”；如需工作区内自动执行文件修改，可手动选择“请求批准”。
- 已有项目、会话、模型配置及系统凭据沿用原存储位置。

## 验证与当前边界

- 发布前回归通过：Go 1,055 项测试及子测试、108 项前端单测、75 项界面回归、14 个真实 Wails 桌面场景，以及 TypeScript、Go vet 和生产构建检查。平台条件及需显式启用的测试按各自条件跳过。
- 发布构建额外核对源码提交、版本元数据、程序包内容和 SHA-256，并在隔离 Windows Runner 上验证真实安装与卸载。
- 此轮已使用指定 DeepSeek 兼容服务验证三协议文件/浏览器操作，以及 Chat、Messages 的电脑截图识别、点击、输入和提交；不代表所有模型、网站和第三方程序都已验收。
- Windows 当前仍为 Job Object 与受限令牌，**没有完整的操作系统文件/网络隔离**；命令仍额外审批，尚未实现自动审批审查器。
- 上下文压缩采用本地提取摘要与裁剪，较早细节可能不再发送给模型，但原始历史继续保留。
- MCP、插件和 Skills 扩展能力已具备，官方社区扩展仓库仍在建设中。

程序使用用户自行配置的供应商、协议及请求头，不包含模型密钥或固定中转凭据。
