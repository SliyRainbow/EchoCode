# EchoCode v0.3.16

## 使用统计与供应商计费

- 新增官方供应商 API Key 的使用量同步与费用统计。
- 支持 OpenAI、Anthropic 等官方计费接口，并保留用户手动校准入口。
- 增加缓存命中、输入 Token、输出 Token、模型费用和供应商状态的展示。

## 界面与窗口

- 新增无边框标题栏和自绘窗口控制，主题切换时同步刷新标题栏。
- 调整设置页、使用统计页和侧边栏布局，改善窄窗口与动态缩放下的显示效果。
- 更新 Windows 应用图标、版本信息和生产构建配置。

## Agent 与工具

- 改进模型路由、推理强度和自定义供应商能力识别。
- 优化工具执行权限、任务范围和 Windows 路径处理。
- 调整 MCP 客户端版本信息和结构化工具结果展示。

## 验证

- Go 全量测试通过。
- `go vet ./...` 通过。
- 前端 TypeScript 检查、自动化测试和 Vite 生产构建通过。
