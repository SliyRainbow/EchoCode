# EchoCode v0.3.18

## 官方扩展中心

- 新增“设置 → 扩展中心”，统一展示 MCP、插件和 Skills。
- 支持搜索、分类、来源核验、权限说明、许可证、安装、更新、卸载和打开安装目录。
- 官方扩展目录由 `SliyRainbow/EchoCode_Extensions` 维护，网络不可用时可回退到最近一次有效缓存。

## CodeGraph 一键接入

- 首个官方目录扩展为 CodeGraph 1.5.0，支持 Windows、Linux 和 macOS 的 x64 / arm64 资源。
- EchoCode 根据当前平台下载上游固定 Release，校验 SHA-256 后安装到用户 LocalAppData，不把大型二进制打进 EchoCode 主程序或 Git 仓库。
- 安装完成后自动生成 MCP 配置并重新连接。
- 扩展详情支持为当前项目建立索引、同步索引和检查索引状态。
- 卸载只移除扩展程序和对应 MCP 配置，保留项目内 `.codegraph` 索引数据。

## 扩展供应链安全

- 下载地址必须使用 HTTPS、固定语义版本并提供 SHA-256。
- 安装流程包含临时下载、哈希校验、ZIP / TAR.GZ 路径穿越防护、条目与解压体积限制、启动文件检查、健康检查和原子提交。
- 安装前展示发布者、源码仓库、固定版本发布页、许可证和真实权限。
- Windows 可正确启动 `.cmd` / `.bat` MCP，后台子进程不再弹出控制台窗口。

## Agent 工作过程

- 对话时间线实时显示权限确认、模型路由、上下文组装、模型连接、首个响应事件、首段文字和工具执行阶段。
- 阶段完成后保留耗时，切换会话或恢复暂停任务时仍可查看。
- CodeGraph 动作使用中文名称与摘要，并按会话工作区隔离项目路径。
- 新增受保护的编码凭据解码工具，敏感明文只进入本机安全卡片，不进入模型上下文、普通消息、Shell、文件或日志。
