# 前端工作台设计与维护

本次界面参考 [Codex 官方产品介绍](https://openai.com/index/introducing-the-codex-app/) 与 [DeepSeek Harness 官网](https://www.deepseek.com/harness/) 展示的工作区组织和界面。采用低对比灰阶、窄导航栏、项目与最近会话列表，以及宽度受控的对话区；深色和浅色共用组件与布局。

## 组件边界

- `frontend/src/app.tsx` 保留会话、任务、队列与后端事件编排。
- `main.tsx` 只挂载 `AppRoot` 与统一样式入口 `styles/index.css`；`AppRoot` 提供界面异常后的重新加载入口。
- `state/workbench-runtime.ts` 统一宿主事件订阅、首次恢复与取消订阅；`state/workbench-navigation.ts` 统一页面历史。设置分类切换也进入前进/后退历史。
- 设置中心通过 `lazy` 按需加载，模型选择菜单直接导入独立组件。主入口 JS 构建产物由约 559 KB 降至 390 KB（未压缩），设置中心单独分包。
- `WorkbenchRail`、`WorkbenchWelcome`、`ComposerActions` 分别管理主导航、空白会话和输入操作。
- `SessionSearch` 搜索已加载的项目和会话，选择结果仍调用原有 Wails 会话接口。
- `ModelRouteMenu` 和 `ReasoningMenu` 使用 Kobalte 菜单；确认与审批使用 Dialog，搜索使用 Combobox，设置开关使用 Switch，导航提示使用 Tooltip。
- `styles/workbench.css` 负责工作台表面、主题变量、响应式布局和 Kobalte 浮层；文件预览、代码编辑器和工具结果继续使用现有组件。
- `styles/settings.css` 统一设置页的内容宽度、表单行、按钮状态、滚动条和分栏拖拽手柄。
- 设置页的标题与内容均占满可用宽度；旧样式中的 760/1120/1180px 页面宽度限制已移除。阅读行长限制只用于段落或单个控件，不限制整个设置工作区。
- `ExtensionCenter` 和 `styles/extensions.css` 管理扩展中心：分类使用 Kobalte Tabs，左侧是紧凑列表，详情区填满剩余空间。宽屏时版本与来源单独成栏，窄屏时按实际容器宽度叠放；布局随界面缩放同步调整。
- `ui/SettingsControls` 封装 Kobalte Button、Select、Slider、RadioGroup 和 Switch；`SettingsRow` 通过上下文为控件提供可访问名称。`ThemePicker` 展示两种主题的缩略预览。
- `SettingsWorkspace` 与 `settings-workspaces.css` 统一 MCP、插件、模型和自动化的列表/编辑布局；共享网格负责间距，设置中心统一提供正文之外的保存底栏。
- `usage.css` 管理总览、账单对账、诊断三个统计视图；累计、会话和单次响应的数据分别呈现。完整检查范围见 [前端界面检查记录](frontend-ui-audit.zh-CN.md)。
- `chat/ReasoningBlock` 使用 Kobalte Collapsible，`styles/motion.css` 集中管理动效，避免不同页面各自定义时长和缓动。

[Kobalte](https://kobalte.dev/) 是 SolidJS 组件库。新增菜单和弹窗优先复用它的键盘导航、浮层定位和焦点管理。组件通过 Portal 渲染时，从根节点继承主题变量；应用会在菜单、搜索和对话框打开期间暂停原生浏览器表面，避免原生窗口遮挡浮层。

Kobalte 的 MIT 许可和上游 NOTICE 保存在 `frontend/public/licenses/kobalte.txt`，会随前端构建资源分发。截图中的品牌、会话与页面内容不从参考产品复制。

## 交互约定

- `Ctrl+N` 新建会话，`Ctrl+K` 搜索会话与项目，`Ctrl+B` 展开或收起侧栏。
- 主导航为工作区、自动化、扩展和设置。扩展页包含发现扩展、MCP 服务器、插件、技能与工具；自动化使用独立页面。统计从设置或对话顶部的“使用统计”进入。
- 设置保留 13 项：外观、键盘快捷键、模型与连接、AI 团队、记忆、权限与执行、浏览器、电脑操控、工作区与环境、Git、使用统计、上下文诊断、关于 EchoCode。原常规连接功能并入模型页，原上下文概况并入上下文诊断；移除静态个性化、命令重复清单和归档空页。
- 会话列表使用“按项目 / 最近”切换并记住选择；归档按钮直接过滤真实会话。输入框项目名为 Kobalte 项目选择器，连接宿主项目切换；跨项目时保护尚未保存的设置和密钥草稿，新建请求进行中阻止重复提交。
- 工作区根路径由项目身份决定，设置中只读展示；额外可写目录随项目保存。Git 页不再重复编辑工作区路径，工作区页不再把额外可写目录标为“项目”。
- 通用 Select 只对实际值变化通知表单，并为包含空字符串的选项生成非空内部键；避免清除模型密钥后的递归更新，以及“跟随当前模型”显示成无选择。SecretInput 的可见状态随供应商切换重置。
- 设置初次打开为常规页，同次运行中记住最近访问的设置分类；自动化和扩展快捷入口不会改写该偏好。
- 附件和输入撤销/重做收在加号菜单；计划、团队和权限收在任务模式菜单。
- 模型与推理强度选择后关闭菜单，并恢复触发按钮的焦点。
- 菜单文字与选中标记使用独立的 `ui-menu-text`、`ui-menu-copy`、`ui-menu-indicator` 类名；推理选项固定预留右侧 16px 标记列，避免通用 span 选择器把勾选标记错误地扩展为半行。选中与未选中项保留相同的文字宽度。
- 危险操作确认默认聚焦取消；审批默认聚焦拒绝，提交期间禁止重复操作。
- 小窗口中右侧文件面板占满工作区，设置分类切换为原生下拉框。
- 界面字体、手动缩放、保存过的侧栏宽度和主题偏好继续生效。
- 侧栏宽度通过带数值的 Kobalte 滑块调整，范围为 220–420px，默认 252px；工作区与设置导航共用该宽度，拖动和键盘调整即时保存。设置布局按实际可用宽度适配，窄窗口的分类菜单说明宽度仍被保留；工作区浮层侧栏限制在视口内，放大界面时也不会重复计入导航栏与标题栏的偏移。
- 设置滑块支持拖动、方向键和 Home/End，显示当前数值与单位；外观设置立即保存，运行配置通过保存栏明确提交或还原。
- 常规页的密钥操作使用文字按钮；模型页将执行策略放在可展开区域，保持主要配置简洁。

## 思考过程与动效

模型返回的可展示推理通过独立的 `reasoning` 字段持久化到消息事件与终止事件，并从历史接口恢复。工具循环累积各轮推理，不再用最后一轮覆盖前面的内容。该字段不参与模型上下文重建，也不替代供应商的签名或加密续接数据。落盘前沿用敏感文本处理。

历史恢复在确认是同一条消息时保留前端标识，另用 `eventId` 保存真实事件 ID；因此流式完成不会重新挂载折叠组件。首次实时推理自动展开，正文开始、工具调用和任务结束均保留当前开合状态，手动选择在切换会话后继续生效。重新启动后历史推理默认折叠，按需查看。旧事件没有该字段时保持兼容，但已经丢失、从未落盘的历史推理无法补回。

页面、菜单、弹窗和折叠区域使用 120–220ms 的短动画；流式文本更新不重复播放入场动画，拖动分栏时不做缓动。带原生浏览器的宿主只淡入，不移动几何位置。系统启用 `prefers-reduced-motion` 时关闭动画、过渡和聊天区平滑滚动，运行状态仍通过文字显示。

## 验证

在 `frontend` 目录执行：

```powershell
bun run check
bun run test:ui
```

`check` 包含 TypeScript、既有 Bun 测试和 Vite 构建。浏览器测试使用独立的 34117 端口，不复用用户正在查看的开发服务；可通过 `ECHOCODE_TEST_PORT` 修改测试端口。Windows 默认使用已安装的 Edge；其他平台可先执行 `bunx playwright install chromium`，也可通过 `PLAYWRIGHT_BROWSER_CHANNEL` 指定浏览器。

浏览器测试在内存中模拟 Wails 接口，覆盖菜单键盘操作、搜索、附件、输入历史、会话切换、流式任务与停止、审批、确认、侧栏调整及深浅主题的不同窗口尺寸。测试不会连接真实模型或写入用户项目。截图和失败轨迹输出到被 Git 忽略的 `frontend/test-results/`。

`settings.e2e.ts` 另外验证密钥按钮的可用状态、滑块键盘与拖动操作、配置保存与还原、手动缩放、设置分类的布局，以及浅色和深色主题的页面截图。

`extensions.e2e.ts` 验证分类键盘导航、搜索与空状态、目录刷新失败、安装/更新/卸载确认和项目操作；在 1920/2560 宽屏与 80% 界面缩放下检查内容是否真正填满可用宽度，并验证窄屏叠放。扩展操作仍通过内存 Wails 模拟接口完成，不会下载或执行真实扩展。

原有源码字符串回归中，已移除对旧弹层定位实现与首页卡片结构的断言，相关行为改由上述浏览器测试验证。

`reasoning-navigation.e2e.ts` 覆盖实时推理、正文开始、最终结果缺字段、前后台任务完成、会话切换、历史重新载入、手动开合、导航历史、设置按需加载与减少动态效果。常规布局测试关闭动画以稳定测量，动效用例单独开启。

Go 回归覆盖推理的持久化/重启恢复、敏感字段处理、工具多轮累积和原有事件日志行为：`go test ./internal/eventlog ./internal/agent`。

## 提示与回退时间线

工作台与设置中心共用 `InlineNotice`，不再使用旧 `error-strip` 的粗体和硬编码主题色。网页预览中的桌面能力限制使用中性提示，实际请求失败保留错误语义和图标；两者都支持关闭与长文本换行。

`TimelinePanel` 使用 Kobalte 非模态 Dialog，挂载于应用容器以遵循界面缩放，顶部避开标题栏。标题、刷新和关闭按钮固定在滚动区之外，检查点按最近优先展示，检查点和对话分支共享滚动区域。关闭后焦点返回入口，查看时间线时仍可使用对话搜索。

加载、失败重试、桌面空记录、网页不可用四种状态分别展示。切换会话会关闭旧面板并丢弃旧请求；任务运行时可以查看记录，但不能恢复文件或切换对话分支。回退/切换前使用现有确认组件说明对话与文件的影响范围，默认聚焦取消。

`CheckpointInfo.isCurrent` 标记实际 head 所在的检查点；`BranchInfo.isCurrent` 仅在 head 已位于该分支末端时成立。回退到祖先检查点后，原末端仍可以切换，即使只保留了一条对话分支。网页预览不再将回退或切分支的调用当作成功的空操作。

`notices-timeline.e2e.ts` 验证提示语义、深浅主题、720–1440px 宽度及 125% 缩放、标题和关闭按钮可见性、长列表、确认与取消、失败重试、运行状态限制和跨会话延迟响应。`TestRewindCanReturnToOriginalTip` 使用临时文件验证旧检查点与原末端之间的文件及对话往返恢复。

2026-10-10 新增导航、项目、自动化和历史保存失败的端到端回归，清理未使用的旧入口、状态和导入；TypeScript 的 `--noUnusedLocals --noUnusedParameters` 检查通过。完整验证与环境约束见 [项目检查与修复记录](project-review-2026-10-10.zh-CN.md)。

这套检查不替代 Wails 原生窗口和真实供应商的桌面验收。
