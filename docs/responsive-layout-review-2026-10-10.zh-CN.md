# EchoCode r10 布局验收

版本：0.3.20 r10 Windows x64 预览版。日期：2026-10-10。

## 本轮修改

1. 回复尾部重新分组，耗时与操作按钮之间留出明确间距，按钮垂直居中；小空间允许换行。
2. 删除对话和输入框的 820px 宽度限制，随当前聊天面板的可用宽度伸缩。统一消息、输入框、状态与提示区域的边距；打开文件等右侧面板时也同步适配。
3. 移除外观设置里的侧栏宽度选项。工作区和设置页的导航边缘使用同一个可拖动分隔控件，宽度跨页面同步并保存。
4. 分隔线支持方向键调整、Home/End 到边界，双击或 Enter 恢复默认宽度；窄屏分类菜单和收起状态下隐藏。
5. 回归发现扩宽后模型选择靠近窗口边缘时，悬停子菜单可能关闭。改用同一 Kobalte 菜单内的供应商分组，直接点击模型，避免左右悬停跨越；增加宽屏及窄屏的实际选择检查。

## 验证结果

- TypeScript、108 项前端单测及 Vite 构建通过。
- 75 项浏览器 UI 回归通过：深浅主题下的宽屏增长、回复尾部间距、右侧面板打开后的适配、两页同步拖动、刷新后保留、复位、125% 缩放和隐藏状态均有覆盖。
- 14 个真实 Wails 场景通过，新增实际鼠标拖动设置侧栏并检查工作区宽度、输入区占用比例与回复按钮间距。
- Wails Windows 生产 clean build 通过；交付程序不包含验收调试端口或隔离配置开关。

本轮为前端调整，Go 业务及权限能力沿用此前版本。测试使用隔离配置和合成工作区，没有调用付费模型或更改用户项目及供应商设置。
